# LtBooks Ver 1.0 部署指南

> 本文件為繁體中文（香港）版，內容與簡體版《部署指南-v1.0.0.md》一致；程式碼、指令與環境變數維持原樣。

適用於兩種發佈包：自動化部署包、人工部署包。所有包共用同一份源碼與
安裝腳本，差異只在系統層動作和是否接入模型輔助排錯。

第 12 節給出單機集中部署的參考基線（服務名、路徑與參數），排查該佈局的問題時以該節為準。

## 1. 環境要求

| 組件 | 最低版本 | 説明 |
| --- | --- | --- |
| 操作系統 | Debian 12 / Ubuntu 22.04+ | 自動模式按 apt 安裝；RHEL 系建議使用手動模式 |
| Nginx | 1.18+ | 提供 HTTPS 與 PHP 轉發 |
| PHP | 8.1+（推薦 8.3） | 需 `curl`、`mbstring`、`xml` 擴展；`gd` 可選 |
| PHP-FPM | 與 PHP 同版本 | 使用獨立 pool 與 socket |
| Python | 3.10+（推薦 3.12） | 後端與安裝腳本 |
| Node.js | 18+（推薦 20） | 隨包會計校驗智能體；自動模式可自動安裝 20 |
| MariaDB | 10.6+（推薦 10.11） | 字元集 `utf8mb4` |
| 其他 | openssl、rsync、curl | 證書、同步、下載 |

建議配置：2 核 / 4 GB 記憶體 / 20 GB 磁盤；有 OCR 與 PDF 匯出需求時預留字體與
WeasyPrint 依賴的磁盤空間。

兩種包結構相同，只有安裝入口不同：

```
LtBooks-Ver1.0-<variant>-<date>/
```

安裝腳本會計算 `MANIFEST.txt` 中每個檔案的 SHA-256；發佈目錄另有整包 `.sha256`。

## 3. 自動化模式

適用：全新 Debian 12 / Ubuntu 22.04+ 伺服器，可聯網，以 root 運行。
**輸入域名或伺服器 IP；域名部署時再填證書通知郵箱（可留空）**，安裝器自動檢查並安裝全部依賴。

```bash
sudo ./install.sh
```

交互提示：

```text
請輸入要部署的域名或伺服器 IP（例如 finance.example.com 或 203.0.113.10）：
> finance.example.com

請輸入用於 Let's Encrypt 證書通知的郵箱（可留空，留空則使用自簽名 HTTPS）：
> admin@example.com
```

郵箱用於證書到期提醒；留空繼續使用自簽名 HTTPS。純 IP 部署不會詢問郵箱。

非交互環境用環境變量提供：

```bash
sudo LTBOOKS_DOMAIN=books.example.com LTBOOKS_SSL_EMAIL=admin@example.com ./install.sh
```

可覆蓋的參數：

| 變量 | 預設值 |
| --- | --- |
| `LTBOOKS_DOMAIN` | 交互輸入；非交互時必填 |
| `LTBOOKS_SSL_MODE` | `auto`（域名+郵箱走 certbot，否則自簽名） |
| `LTBOOKS_SSL_EMAIL` | 交互輸入（可留空） |
| `LTBOOKS_APP_DIR` | `/opt/ltbooks` |
| `LTBOOKS_WEB_ROOT` | `/var/www/ltbooks` |
| `LTBOOKS_UPLOAD_DIR` | `/var/lib/ltbooks/uploads` |
| `LTBOOKS_BACKUP_DIR` | `/var/backups/ltbooks` |
| `LTBOOKS_DB_HOST` / `PORT` | `127.0.0.1` / `3306` |
| `LTBOOKS_DB_NAME` / `USER` | `ltbooks` / `ltbooks_app` |
| `LTBOOKS_DB_PASSWORD` | 隨機 48 位十六進制 |
| `LTBOOKS_WEB_USER` | 自動探測 `www-data` / `nginx` / `apache` / `www` |

例：

```bash
sudo LTBOOKS_DOMAIN=books.example.com \
     LTBOOKS_SSL_EMAIL=admin@example.com \
     ./install.sh
```

執行後：

```bash
systemctl status ltbooks-api
systemctl list-timers ltbooks-backup.timer
nginx -t
php-fpm8.3 -t
```

自動化模式會創建：

- 系統用户/組 `ltbooks`（服務運行賬號），並把 Web 賬號加入該組；
- `/etc/php/<ver>/fpm/pool.d/ltbooks.conf` 獨立 pool，socket `/run/php/ltbooks.sock`；
- `/etc/nginx/sites-available/ltbooks.conf`（或 `conf.d/ltbooks.conf`）；
- `/etc/systemd/system/ltbooks-api.service`；
- `/etc/systemd/system/ltbooks-backup.{service,timer}`，timer 每分鐘調用一次 tick，
  具體時間由介面「自動備份設定」決定（香港時間，預設 09:00、17:00）；
  自動備份為單檔案滾動更新，手動備份為完整備份。

### 3.1 域名與 IP

| 輸入 | HTTPS | 説明 |
| --- | --- | --- |
| 已解析到本機的域名 + 郵箱 | Let's Encrypt 公開證書 | 瀏覽器直接受信 |
| 域名 + 郵箱留空 | 自簽名證書 | 首次訪問需手動信任；之後可用 `LTBOOKS_SSL_EMAIL` 重新申請 |
| 純 IP | 自簽名證書 | Let's Encrypt 不支援純 IP；綁定域名後重新運行並設定 `LTBOOKS_SSL_EMAIL` 即可申請公開證書 |

交互安裝會在域名之後詢問一次證書通知郵箱；純 IP 或 `selfsigned`/`off` 模式不詢問。

## 4. 人工模式

適用：已有面板的主機、內網或需要自行控制系統軟件版本的環境。**系統環境由人工安裝**，
`install-manual.sh` 只部署應用。

### 4.1 人工安裝環境

以 Debian / Ubuntu 為例，完整命令見 [HOWTO.md](HOWTO.md) 第 2.1 節。最低版本：

| 組件 | 最低 |
| --- | --- |
| PHP | 8.1（擴展 curl、mbstring、xml、pdo_mysql） |
| Python | 3.10 |
| Node.js | 18 |
| MariaDB | 10.6 |

### 4.2 部署應用

```bash
unzip LtBooks-Ver1.0-manual-clean-<date>.zip
cd LtBooks-Ver1.0-manual-clean-<date>
./install-manual.sh
```

只做：創建目錄、建庫導表、創建管理員、安裝前後端、生成示例配置。不安裝系統軟件、
不創建系統賬號、不啓動服務、不修改面板配置。

安裝後在 `<應用目錄>/setup/` 得到：

- `nginx-ltbooks.conf.example`
- `php-fpm-ltbooks.conf.example`
- `ltbooks-api.service.example`
- `ltbooks-backup.service.example` / `.timer.example`
- `ssl/fullchain.pem`、`ssl/privkey.pem`（自簽名兜底）

接入面板時注意：

1. PHP-FPM pool 的 `user` / `group` 必須與讀取上傳目錄的 Web 賬號一致；
2. 站點根目錄指向前端目錄，`/files/` 必須拒絕訪問；
3. 上傳目錄不放在 Web 根目錄；
4. 以 root 運行安裝器時，若未指定 `LTBOOKS_WEB_USER`，會選用系統中已存在的
   Web 賬號；以普通用户運行時預設使用當前賬號。

啓動後端：

```bash
<應用目錄>/venv/bin/python <應用目錄>/api.py
```

或使用 `setup/ltbooks-api.service.example` 註冊服務。

## 5. HTTPS

- `LTBOOKS_SSL_MODE=auto`：有域名與郵箱時用 Certbot 申請，否則自簽名；
  交互安裝會在域名後詢問證書通知郵箱（可留空）；
- `certbot`：強制申請公開證書，失敗即報錯（郵箱必填）；
- `selfsigned`：只生成本地證書，適合內網驗收；
- `off`：僅 HTTP。**不推薦**：會話 Cookie 帶 `Secure`，HTTP 下無法登入。

證書路徑：自動模式 `/etc/ssl/ltbooks/`；手動模式 `<應用目錄>/setup/ssl/`。

## 7. 運行時配置（.env）

安裝器生成，權限 600/640。關鍵項：

| 鍵 | 用途 |
| --- | --- |
| `LEDU_DB_*` | 資料庫連接 |
| `LEDU_API_HOST` / `PORT` | 後端監聽，預設 `127.0.0.1:8099` |
| `LEDU_API_TOKEN` | 前端到後端的內部令牌，≥32 位隨機串 |
| `LEDU_WEB_ROOT` | 前端目錄，供 PDF/Logo 讀取 |
| `LEDU_STORAGE_DIR` | 證書、臨時檔案等應用數據 |
| `LEDU_UPLOAD_DIR` / `LEDU_UPLOAD_DIRS` | 票據附件目錄（可多路徑） |
| `LEDU_BACKUP_DIR` / `KEEP` / `LOCK` | 備份目錄、保留天數、鎖檔案 |
| `LEDU_AGENT_PRESET` | 隨包會計校驗智能體目錄 |
| `LEDU_NODE_BIN` | Node 可執行檔案 |
| `LEDU_LLM_*` | 模型接口，介面設定優先 |
| `LEDU_VISION_API_KEY` | 視覺/OCR 接口 |
| `LEDU_SMTP_*` | 郵件，介面設定優先 |

修改 `.env` 後需重啓後端：`systemctl restart ltbooks-api`。

## 8. 部署後驗證

```bash
curl -fsS http://127.0.0.1:8099/health
curl -kfsS https://<域名>/login | head
systemctl is-active ltbooks-api
```

資料庫核對（應只有實體、科目、税率與管理員）：

```sql
SELECT COUNT(*) FROM information_schema.tables
 WHERE table_schema='ltbooks' AND table_type='BASE TABLE';   -- 50
SELECT COUNT(*) FROM accounts;    -- 108
SELECT COUNT(*) FROM tax_rates;   -- 12
SELECT COUNT(*) FROM customers;   -- 0
SELECT COUNT(*) FROM journal_entries; -- 0
```

登入後檢查：儀表板無報錯、報表期間切換正常、財務報表可匯出 PDF、
「設定 → 備份與恢復」可創建並下載備份。

## 9. 從舊環境遷移

1. 舊環境「備份與恢復」創建備份並下載；
2. 新伺服器安裝乾淨包（同一版本）；
3. 新環境「備份與恢復」上傳並恢復；
4. 複製舊 `.env` 中的模型、SMTP 與令牌配置，或在新介面重新填寫；
5. 校驗客户/供應商數量、最近一期報表與備份前一致。

## 10. 卸載

```bash
systemctl disable --now ltbooks-api ltbooks-backup.timer
rm -f /etc/systemd/system/ltbooks-api.service /etc/systemd/system/ltbooks-backup.*
rm -f /etc/nginx/sites-enabled/ltbooks.conf /etc/nginx/sites-available/ltbooks.conf
rm -f /etc/php/*/fpm/pool.d/ltbooks.conf
systemctl reload nginx && systemctl restart 'php*-fpm'
```

數據目錄（`/opt/ltbooks`、`/var/lib/ltbooks`、`/var/backups/ltbooks`）在確認已備份後
再刪除；資料庫用 `DROP DATABASE ltbooks;` 清理。

## 11. 常見問題

| 現象 | 處理 |
| --- | --- |
| `Missing PHP extension` | 安裝對應擴展後重試；僅 `curl`、`mbstring`、`xml` 為必需 |
| `Node.js 18 or newer is required` | 自動模式會安裝 Node 20；手動模式請先升級 |
| Nginx 啓動失敗 | `nginx -t`；確認 socket 路徑與 PHP-FPM pool 一致 |
| 502 | 後端未啓動或端口不同；`systemctl status ltbooks-api` |
| 登入循環 | 未啓用 HTTPS |
| 上傳 413 | 調大 Nginx `client_max_body_size` 與 PHP `upload_max_filesize` |
| 證書不受信任 | 自簽名屬預期；生產請配置真實證書 |

## 12. 單機集中部署基線（示例）

以下是一個單機集中部署的參考基線。數值取自真實運行環境，涉及域名、庫名等已替換為
示例值；用於説明「所有組件裝在一台機器、共用同一套目錄」時的實際配置形態。

安裝包預設把前端放在 `/var/www/ltbooks`，本節示例則把所有內容集中在 `/opt/ltbooks`，
兩者都可用，排障時請先確認自己屬於哪種佈局。

### 12.1 路徑與服務

| 項目 | 示例值 |
| --- | --- |
| 應用根 | `/opt/ltbooks`（`app/`、`web/`、`storage/`、`uploads/`、`backups/`、`archive/`） |
| 前端站點 | `/opt/ltbooks/web`；可由 `/var/www/ltbooks` 軟鏈指向 |
| 域名 | `finance.example.com` |
| 後端服務 | `ledu-api.service` → `127.0.0.1:8099` |
| 後端日誌 | `/var/log/ledu-api.log` |
| Web 伺服器 | Nginx；站點配置 `/www/server/panel/vhost/nginx/finance.example.com.conf` |
| PHP | 8.3，FPM pool `www`（`/etc/php/8.3/fpm/pool.d/www.conf`） |
| 資料庫 | MariaDB `ltbooks`，用户 `ltbooks`，`127.0.0.1:3306` |
| 證書 | Let's Encrypt，有效期至 2027-02-17，acme.sh 自動續期 |

### 12.2 關鍵參數

```ini
; /etc/php/8.3/fpm/pool.d/www.conf
pm = dynamic
pm.max_children = 20
pm.start_servers = 5
pm.min_spare_servers = 5
pm.max_spare_servers = 10
```

原值為 `5 / 2 / 1 / 3`，2026-11-21 因出現 `server reached pm.max_children`
告警上調。修改後執行 `systemctl reload php8.3-fpm`。

```ini
; /etc/logrotate.d/ledu-api
/var/log/ledu-api.log {
    su root root
    daily
    rotate 14
    missingok
    notifempty
    compress
    delaycompress
    copytruncate
    create 0640 root root
}
```

`su root root` 是因為 `/var/log` 為 `root:syslog 775`；`copytruncate` 保證
不重啓後端。

### 12.3 自動備份

線上用系統 crontab，每分鐘由 `flock` 互斥調用一次 `tick`：

```cron
* * * * * /usr/bin/flock -n /var/run/ltbooks-auto-backup-tick.lock \
  /usr/bin/env -u LD_LIBRARY_PATH \
  /opt/ltbooks/app/venv/bin/python /opt/ltbooks/app/tools/auto_backup.py tick \
  >> /opt/ltbooks/backups/auto-backup.log 2>&1
```

調度時間存於 `settings` 表的 `backup.schedule`，預設香港時間 09:00 / 17:00；
保留 180 份（`LEDU_BACKUP_KEEP`）。首次必須先建立完整基線：

```bash
cd /opt/ltbooks/app && ./venv/bin/python tools/auto_backup.py create --full
```

### 12.4 部署後驗證

```bash
systemctl is-active nginx php8.3-fpm ledu-api cron
curl -fsS http://127.0.0.1:8099/health
curl -fsS -o /dev/null -w '%{http_code}\n' https://finance.example.com/
crontab -l | grep auto_backup
ls -lh /opt/ltbooks/backups/
```

```bash
# 後端迴歸
cd /opt/ltbooks/app && PYTHONPATH=. ./venv/bin/python -m unittest discover -s tests -p 'test_*.py'
# 前端語法
find /opt/ltbooks/web -name '*.php' -print0 | xargs -0 -n1 env -u LD_LIBRARY_PATH php -l
```

期望：服務 `active`、`health` 200、首頁 200、cron 命中 1 條、備份目錄至少一份
`tar.gz`、131 個後端用例通過、PHP 語法零失敗。

> 本機命令需要 `env -u LD_LIBRARY_PATH` 前綴，否則某些二進制會因
> `GLIBCXX_3.4.32 not found` 失敗。
