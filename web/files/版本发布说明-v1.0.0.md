### 0.4 部署脚本

自动部署包在询问域名/IP 之后新增一步「Let's Encrypt 证书通知邮箱」：

- 填写有效邮箱 → 申请公开证书；直接留空 → 继续使用自签名 HTTPS；
- 纯 IP 部署、`selfsigned` 或 `off` 模式不询问邮箱；
- `LTBOOKS_SSL_EMAIL` 仍可预先提供以跳过交互；`LTBOOKS_SSL_MODE=letsencrypt`
  时邮箱必填，缺失会立即报错。

详细参数见 [部署指南-v1.0.0.md](部署指南-v1.0.0.md) 第 12 节。

## 2. 本次整改对照

### 2.1 UI、品牌与备份

- 产品名统一为 LtBooks；浏览器标题、单据页脚、报表页脚、PDF/DOCX 页脚同步更新。
- 左上角品牌区重新设计：标识、产品名与当前账套/期间信息分层展示，去掉拥挤布局。
- 「设置 → 外观与配色」重做为可视化配色卡，新增 6 套方案，合计 8 套
  （科技蓝、暖纸灰、雾蓝低对比、墨绿沉静、冰川青、赤陶暖棕、石墨夜色、午夜靛蓝）。
- 「设置 → 备份与恢复」支持数据库 + 上传票据/附件的一致备份、下载、删除、校验与恢复；
  手动与自动备份分开两个列表。自动备份默认每天 09:00、17:00（香港时间），可在界面
  自定义（最多 4 个时间），执行**单文件滚动备份**，无基线时先建立完整包；**手动备份
  始终为完整备份**并成为后续自动更新的文件。恢复时直接读取该文件，无需回溯链条，
  保留最近 180 份。

### 2.2 AI 工作台

- 建单、记账、查数、对账、导出集中在 AI 工作台，不再跳转人工页面。
- 票据先识别内容与业务性质，再给出建议科目与单据的结果卡片；仅在票面无金额、
  无日期、收付款方不明等确实缺失时提问，不再固定反问「支出性质」。
- 识别规则覆盖常见费用、服务、租金、薪酬、银行费用与关联往来，并记录学习结果。
- 手机网页端支持拍摄或选择文件上传票据并识别，与桌面端共用同一识别与确认链。

### 2.3 单据、邮件与多币种

- 「设置 → 邮件」界面重做：分组卡片、连接测试、发件人信息与说明分离。
- 报价单、销售订单、发票、账单、采购订单、贷记单均可发送邮件，模板与打印件一致。
- 发票草稿可再次编辑：编号不变，保存后重新校验并重置复核状态；已过账发票需先冲销。
- 客户备注与条款仅作内部记录，不会出现在导出的发票 PDF 中。
- 发票、账单、贷记单、报价单、订单等 PDF 的公司信息页脚统一固定在纸张底边上方 10mm，
  多页时每页重复，正文与页脚不再留出大块空白或相互重叠。
- 功能菜单按会计逻辑排序：销售 → 采购 → 银行 → 会计 → 报表 → 设置。
- 外币单据统一显示原币金额、汇率与折算后的功能货币金额；整份单据只用当前语言，
  不出现三语混排。

### 2.4 列表与菜单

- 发票与账单列表新增收款/付款进度列（已核销比例与剩余金额）。
- 「报表」菜单收敛为报表中心、财务报表、利得税三个入口，消除与报表中心重叠。
- 「AI 助手 / 智能体 / AI 助手仪表板」统一为「AI 工作台」；智能体配置页命名为
  「智能体管理」。

### 2.5 仪表盘与财务分析

- 提供期间可选的公司财务分析报告：本月、指定月份、自然年、财务年、开业至今、自定义。
- 报告含核心指标、图表、财务报表与 AI 定性解读；数字全部来自确定性报表函数，
  AI 不生成数字，模型不可用时回退确定性文案并标注。
- 支持三语 PDF 与 Word（DOCX）导出；为财务主管智能体配置取数、比率、趋势与
  异常说明能力。按验收反馈，仪表盘不内嵌该报告组件，页面保持简洁。

### 2.6 代码与文档

- 源文件补充统一的版权与 SPDX 许可标识，主要模块保留解释性注释。
- 移除旧品牌、旧产品缩写及指定云服务/邮件服务/主机面板的绑定描述与示例。
- 删除 `files` 下旧重构方案、施工报告、旧测试报告与验收提示词，重做
  README、HOWTO、部署指南、开发全路径与发布说明。
- 删除后端旧的 `docs/`、`docs-legacy/` 目录与旧变更日志内容。

### 2.7 部署包

- 自动化包：输入域名或服务器 IP（域名部署时再填可选的证书通知邮箱），安装器检查并安装 Nginx、MariaDB、PHP-FPM、
  Python、Node.js、OCR/PDF 字体与 Certbot；生成独立 PHP-FPM pool、站点、systemd
  服务与备份 timer；域名+邮箱申请公开证书，纯 IP 或未提供邮箱时使用自签名 HTTPS。
- 人工包：系统环境由运维手动安装；脚本仅初始化目录、数据库、账号与示例配置，
  不安装系统软件、不创建系统账号、不启动服务。
- 原 AI 部署包已取消；模型能力保留在应用内的 AI 工作台，不再参与部署流程。

### 3.4 空库隔离安装

- 重复执行安装：数据库行数、管理员口令哈希、`.env` 与初始凭据文件均未改变。

- 上传目录与凭据文件权限符合预期（凭据 600，上传目录仅服务账号与 Web 账号可写）。

### 3.5 安装器输入与证书分支

验证三种入口：交互输入域名、域名后交互输入证书邮箱、交互输入纯 IP。
域名 + 邮箱走公开证书分支；纯 IP 或邮箱留空自动切换到自签名证书，不调用 Certbot。
`LTBOOKS_SSL_MODE=letsencrypt` 时邮箱必填，缺失或格式非法会立即报错。非交互运行且未提供
`LTBOOKS_DOMAIN` 时明确报错退出，不会静默使用占位域名。

## 4. 已知事项与限制

1. 真实账套中一笔 20,000 元利息计入短期借款，属非现金事项，报表在
   `cash_unclassified` 单列。系统不会为凑平而改写分录。
2. 自动部署包的完整系统安装需在全新 Debian/Ubuntu 上执行；本次验收在现有生产
   主机上完成脚本、依赖检查、生成配置与隔离空库安装验证，未在本机重装系统组件。
3. 干净包默认公司为 `My Company`、功能货币 HKD、年结日 12-31；首次登录后按实际
   资料修改。
4. 自签名证书仅用于内网或验收；生产请配置真实证书，否则浏览器会提示不受信任。
5. 大模型与 SMTP 凭据只存于 `.env` 或界面设置，不进入安装包与备份包。

## 5. 升级与回滚

1. 升级前在「设置 → 备份与恢复」创建备份并下载；
2. 用相同参数执行新版本安装脚本，已有数据库与账号会保留；
3. 回滚时恢复升级前备份，并用上一版本源码替换应用目录；
4. 重启后端服务并核对最近一期报表。

## 6. 校验

```bash
sha256sum -c LtBooks-Ver1.0-auto-clean-20261121.tar.gz.sha256
sha256sum -c LtBooks-Ver1.0-manual-clean-20261121.zip.sha256
```
